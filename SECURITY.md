# Security Policy

The images here are the base of the AnsibleForms images, so a security problem in them is a
problem in AnsibleForms. Please follow the
[AnsibleForms security policy](https://github.com/ansibleforms/ansibleforms/security/policy)
and report privately through its
**[Report a vulnerability](https://github.com/ansibleforms/ansibleforms/security/advisories/new)** page.

**Please do not open a public issue for a security problem.**

If the problem is specific to an image here, for example a package installed that should
not be, use **[Report a vulnerability](https://github.com/ansibleforms/base-images/security/advisories/new)**
on this repository instead.

An outdated package in an image is usually fixed by a rebuild, which picks up the current
OS and Python packages: open an issue or run the Build workflow.
